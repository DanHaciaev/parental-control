# Проверка на реальных телефонах

Весь код готов (Фазы 0–6). Это чек-лист, чтобы пройти всё живьём и поймать реальные проблемы (эмулятор не показывает поведение Samsung по батарее/Accessibility).

## Установка

APK лежат в:
- `app-parent\build\outputs\apk\debug\app-parent-debug.apk` — на телефон мамы
- `app-child\build\outputs\apk\debug\app-child-debug.apk` — на телефон сына

Через USB (по одному телефону за раз, включить «Отладка по USB» в настройках разработчика):
```
adb install -r app-parent\build\outputs\apk\debug\app-parent-debug.apk
adb install -r app-child\build\outputs\apk\debug\app-child-debug.apk
```
Или просто скопировать `.apk` на телефон и установить через файловый менеджер (разрешить установку из неизвестных источников при первом запросе).

**Важно:** не забудь переопубликовать актуальный `firestore.rules` в консоли Firebase, если ещё не делал(а) после последних изменений (задания, hardening полей).

## Порядок проверки (по фазам)

### 1. Вход и привязка
- [ ] Регистрация мамы по email на телефоне мамы.
- [ ] Экран генерации кода появляется, код виден.
- [ ] На телефоне сына: ввод кода → успешная привязка → переход дальше.
- [ ] Если выключить и снова включить приложение мамы (или сменить телефон, переустановив APK и войдя тем же email) — семья и привязка ребёнка восстанавливаются автоматически.

### 2. Разрешения у ребёнка
- [ ] Экран разрешений — каждая кнопка реально открывает нужный системный экран.
- [ ] На Android 13+ проверить пункт «Специальные возможности» — если серый/заблокированный, всплывающая подсказка про «Разрешить ограниченные настройки» должна появиться и помочь.
- [ ] После выдачи всех разрешений — автоматический переход на главный экран, без зависаний.
- [ ] Постоянное уведомление «Родительский контроль активен» видно в шторке.

### 3. Лимиты и блокировка (ядро)
- [ ] У мамы поставить лимит 1 минута на тестовое приложение (например, калькулятор).
- [ ] На телефоне сына открыть это приложение, подождать ~1 минуту — должен появиться экран блокировки поверх приложения, с кнопкой «На главный экран» и «Попросить ещё времени».
- [ ] Нажать «Попросить ещё времени» — у мамы во вкладке «Задания» должна появиться заявка; подтвердить (+15 мин) — у сына лимит должен увеличиться в реальном времени.
- [ ] Полностью заблокировать другое приложение у мамы — на телефоне сына оно должно закрываться сразу при открытии.
- [ ] Перезагрузить телефон сына — блокировка/лимиты должны продолжать работать после перезагрузки (проверка `BootReceiver`).

### 4. Защита от удаления
- [ ] На телефоне сына зайти в Настройки → Приложения → «Семейный помощник» → попытаться удалить. Должно либо не пускать, либо сразу перебрасывать назад.
- [ ] На телефоне мамы аналогично — должен запросить код защиты.
- [ ] Ввести правильный код у мамы → должна открыться системная возможность удаления.
- [ ] У мамы в меню (⋮) → «Разрешить удаление приложения у ребёнка» → подтвердить. На телефоне сына (может понадобиться открыть приложение) должна появиться кнопка «Удалить приложение».

### 5. Геолокация
- [ ] Разрешить геолокацию «Всегда» на телефоне сына.
- [ ] У мамы во вкладке «Карта» — через 10-15 минут должна появиться метка с реальным местоположением.

### 6. Прочее
- [ ] Разрядить (или симулировать через `adb shell dumpsys battery set level 10`) батарею сына до 15% — у мамы должно появиться событие в «Журнале».
- [ ] Настроить ночной режим у мамы на ближайшие несколько минут — на телефоне сына в это время должен появиться экран «Ночной режим».
- [ ] Создать задание у мамы («Задания» → «+») → на телефоне сына на главном экране в разделе «Задания от родителей» нажать «Готово» → у мамы во вкладке «Задания» подтвердить → бонусные минуты должны примениться.
- [ ] Меню ⋮ → «Диагностика устройства ребёнка» у мамы — все пункты должны быть зелёными (✅) при корректной настройке.

## Специально для Samsung (One UI)

- [ ] Настройки → Обслуживание батареи и устройства → Батарея → Ограничения фона → убедиться, что «Семейный помощник» **не** в списке «Спящие приложения» / «Глубокий сон».
- [ ] Закрепить оба приложения в списке недавних (long-press на карточке приложения → значок замка), чтобы система не выгружала их из памяти.
- [ ] Оставить телефон сына без дела на несколько часов (или на ночь) и проверить утром, что сервис/уведомление всё ещё активны — это главный тест на живучесть против агрессивного энергосбережения Samsung.
